Did everything arrive?

Every row the source produced reaches every layer exactly once. These checks never look at meaning, only at counts and freshness.

Do we still recognise people?

This is the family that broke on 8 April. It reads the raw browser and session identifiers on bronze. These are monitoring signals, not reported numbers: unique visitors are counted on the contact id and stayed correct.

Does the data still look like the data?

Shape rather than volume: the columns, the value formats, and the tracking software itself. This family catches a release before it reaches a number.

One layer, one responsibility

Each layer earns its own checks. Bronze watches arrival and the raw identifiers, silver watches the person resolution, gold watches the aggregate. A failure inside one layer is invisible to the others.
